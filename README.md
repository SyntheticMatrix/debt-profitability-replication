# Corporate debt and firm profitability

This repository is the home for replication materials accompanying our manuscript on corporate debt, asset composition, and firm profitability.

The study examines the relationship between the debt-to-asset ratio (DAR) and return on assets (ROA), using a model with separate adjustment of liquid and non-liquid assets and a general equilibrium extension with firm entry and exit.

## Replication package

The replication package is being prepared. This initial page establishes the repository address for the manuscript. Model solution routines, numerical validation records, and instructions for reproducing the figures and tables will be added here.
